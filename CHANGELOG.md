# Changelog

## 1.0.0 (2026-11-04)

### Features
- Initial release of Portugal IPTV Player
- Vue.js component architecture
- Professional UI with glass morphism design
- Channel list with search and filtering
- Video player with playback controls
- Auto-refresh functionality
- Online/offline status monitoring

### Technical Changes
- Migrated from monolithic HTML to Vue.js component structure
- Added TypeScript support
- Implemented design system with CSS variables
- Created service layer for channel management
- Added responsive design

### Breaking Changes
- The interface is now a single-page application
- Previous URL structure changed from `index.html` to `http://localhost:3000`
